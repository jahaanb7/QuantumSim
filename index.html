How this simulation works +

We evaluate analytic, nonrelativistic Coulomb orbitals: ψ(r, θ, φ) = Rₙℓ(r) Yℓ(θ, φ). The radial factor uses associated Laguerre polynomials; the angular factor uses real spherical harmonics. The cloud is sampled from |ψ|² with a seeded Monte Carlo sampler.

The model is for a single electron and a fixed, pointlike nucleus. H, He⁺, and Li²⁺ are hydrogen-like systems. We omit electron interactions, spin, relativity, fine structure, and external fields. Energies use Eₙ ≈ −13.606 Z²/n² eV and distances use a₀ ≈ 52.918 pm. Shell and subshell changes reframe the view. Changing nuclear charge keeps the same frame, so contraction is visible. The 95% radius encloses 95% of the electron’s position probability. A cutaway hides x > 0 to reveal internal nodes.

The labels pₓ, pᵧ, dₓᵧ and related real orbitals are real linear combinations of the complex m eigenstates. The orientation selector therefore uses real basis labels, rather than claiming each shape has one definite magnetic quantum number. Colours indicate opposite real signs; a global sign reversal describes the same state.
